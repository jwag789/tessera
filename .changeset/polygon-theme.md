New Polygon theme: matte cool-grey plastic with dark recessed panels, hard 1-2px bevels instead of soft shadows, a green, red, blue and pink accent set for status and selection, a menu cursor on the selected item, Silkscreen pixel headings with Space Mono labels, and faint dither and scanlines on large surfaces. Import `@tessera/react/themes/polygon.css` and `@tessera/react/themes/polygon-fonts.css`, then set `brand="polygon"`.
