# EmptyState

What a list or page shows before it has content: what will appear here, and how to add the first one.

**Consumer provides:** `title`, optional `description`, `actions` (one primary, maybe one secondary), `illustration` (replaces the default tiles), `seed` (changes the tile pattern).

**Motion:** the tiles drop in, and the saffron one lands last and slightly out of place.

- Write the title as the state ("No applications yet"), and the description as the benefit, not an instruction manual.
- Always offer the next action. An empty state with no way forward is a dead end.
- For "no results" after a search, say what was searched and offer to clear the filters.
